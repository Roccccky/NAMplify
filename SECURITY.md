# Security

NAMplify is early-beta software.

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/Roccccky/NAMplify/security/advisories/new),
not as a public issue.

NAMplify talks to TONE3000 over HTTPS only. The TONE3000 sign-in returns through the `namplify://`
link; NAMplify keeps the resulting session on your computer and never asks for your password.
See [PRIVACY.md](PRIVACY.md).
